해외 소비 한눈에

실행
이 폴더에서 다음 명령을 실행합니다.
python -m pip install -r requirements.txt
python -m streamlit run app.py

업로드 없이 public_data.csv를 자동으로 읽어 실제 분석을 표시합니다.
기본 데이터의 개별 가맹점명은 익명 처리했습니다.
카드번호·승인번호·거래시각·현지금액은 기본 데이터에서 제외했습니다.
날짜·업종·국가·원화금액·상태는 공개 앱 방문자도 확인하고 다운로드할 수 있습니다.
원본 CSV의 두 줄을 한 거래로 합칩니다. 원본 파일은 변경하지 않습니다.

집계 기준
- 원본 국가 값 280은 사용자가 확인한 체코로 표시하고 기존 체코 내역과 합산합니다.
- 정상 상태이고 원화금액이 양수인 승인만 소비 차트에 포함합니다.
- 취소·매출취소는 별도 표시하며 원거래와 자동 상계하지 않습니다.
- 음수·0원·기타 상태는 차트에서 제외하고 상세 내역에 표시합니다.
- 원화 환산 승인액 기준으로, 실제 청구액이나 최종 순지출과 다릅니다.
- 중복처럼 보이는 거래도 원본에 있는 그대로 보존합니다.
- 카드번호·승인번호는 분석 및 다운로드에서 제외합니다.

배포
이 폴더의 app.py, data_utils.py, requirements.txt, public_data.csv를 GitHub 저장소에 올립니다.
https://share.streamlit.io 에서 저장소와 app.py를 선택해 배포합니다.
폴더째 올린 경우 Main file path에 overseas_dashboard/app.py 등 실제 경로를 입력합니다.
개인 승인 내역 CSV 원본은 저장소에 올리지 않습니다. 공개용 public_data.csv만 포함합니다.
업로드 파일은 앱 서버 메모리에서 처리되며 별도 파일·DB에 저장하지 않습니다.
